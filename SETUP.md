# K.I.A Home Service - Website Setup Instructions

## ✅ Files Deployed

- `index.html` - Complete website structure
- `styles.css` - Premium styling with light/dark mode
- `script.js` - Full functionality (calculators, portal, admin)

## 📁 Assets Folder Setup

Create an `/assets` folder in your repository root and add:

### Required Image Files:

1. **Logo** (required for header/footer)
   - `logo.png` - Your K.I.A Home Service logo

2. **Window Washing Images**
   - `window-clean-1.jpg`
   - `window-clean-2.jpg`

3. **Pressure Washing Images**
   - `pressure-wash-1.jpg`
   - `pressure-wash-2.jpg`

4. **Car Detailing Images**
   - `car-detail-1.jpg`

5. **Before/After Slider Images**
   - `before.jpg` - Before image
   - `after.jpg` - After image

### Image Sources:

You can download free images from:
- **Pexels** (pexels.com)
- **Unsplash** (unsplash.com)
- **Pixabay** (pixabay.com)

**Search for:**
- "clean windows"
- "pressure washing driveway"
- "car detailing"
- "dirty driveway"
- "clean driveway"

## 🚀 GitHub Pages Setup

1. Go to **Settings** → **Pages**
2. Select **Deploy from a branch**
3. Choose `main` branch and `/root` folder
4. Save

Your site will be live at: `https://KIAHomeService.github.io/K.I.A-Home-Service`
